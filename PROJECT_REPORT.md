# Movie Recommendation System

## Introduction

The Movie Recommendation System is a web application that recommends movies using a graph database.

Unlike relational databases, graph databases efficiently represent relationships between movies, genres, actors, directors, and users.

---

# Objectives

- Learn Graph Databases
- Build REST APIs
- Perform CRUD Operations
- Recommend Movies
- Understand Graph Traversal
